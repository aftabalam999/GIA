# Security Policy

Security is a priority for GIA. We take vulnerability reports seriously and appreciate responsible disclosure from the security community.

## Supported Versions

Security updates are provided for the following versions:

| Version | Supported |
|---|---|
| Latest release | Yes |
| Previous releases | No |
| `main` branch | Best-effort |

Only actively maintained releases are eligible for security updates.

## Reporting a Vulnerability

If you discover a security vulnerability in GIA, please report it responsibly.

**Preferred reporting method:**

Use GitHub's private vulnerability reporting feature:

[Report a vulnerability](https://github.com/aftabalam999/GIA/security/advisories/new)

If private reporting is unavailable, contact the project maintainers through a private communication channel.

Do not disclose vulnerabilities publicly until the maintainers have had an opportunity to investigate and address them.

### What to Include

Please provide:

- A clear description of the vulnerability.
- Steps to reproduce the issue.
- Potential security impact.
- Affected components or versions.
- Proof of concept, if available.
- Suggested mitigation, if known.

### Response Process

After receiving a vulnerability report:

1. The maintainers will review the report.
2. The reporter will receive an acknowledgment within 7 days where contact details are available.
3. The maintainers will investigate and assess the severity.
4. A fix or mitigation will be developed where appropriate.
5. The reporter will be informed about the resolution.
6. Public disclosure will be coordinated responsibly.

Response and remediation timelines depend on the vulnerability's severity and complexity.

## Scope

Security reports are welcome for vulnerabilities affecting:

- GIA frontend application.
- Backend APIs and services.
- AI service and model integrations.
- Voice input and speech output.
- Local command execution and system permissions.
- Authentication and authorization.
- Data storage and sensitive information handling.
- Desktop application and operating system integration.

## Responsible Disclosure

Please:

- Do not access or modify other users' data.
- Do not disrupt services or systems.
- Do not perform destructive testing.
- Do not publish exploit details before coordinated disclosure.
- Do not use vulnerabilities to gain unauthorized access.

## Security Updates

Security fixes will be released through the project's official repository whenever appropriate.

We appreciate everyone who helps make GIA safer.
